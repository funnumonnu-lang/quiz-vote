# 部門間ネットワーク図 (dept-network)

エクセルを読み込むと部門間の関係性をネットワーク図に描く、単一HTMLのツール。

## 完全オフライン版

`dept-network.html` は **外部と一切通信しません**。

- Cytoscape.js と SheetJS をファイル内に埋め込み済み。CDN参照なし
- 外部フォントの読み込みなし（Windows標準フォントで表示）
- 通信を発生させる記述はゼロ（`<script src>` / `<link>` / `fetch` / `XMLHttpRequest` / `WebSocket` / `sendBeacon` / `importScripts` / `@import` すべて0件）
- 読み込んだエクセルはブラウザのメモリ内だけで処理され、どこにも送信されない
- ネットワークを遮断した環境、社内ファイルサーバー、USB経由でも動作する

ダブルクリックで開くだけ。インストール・ビルド不要。ファイル名は自由に変更してよい。

## 画面

左パネルの見出しはクリックで開閉できる。任意の設定（人数・並び順・比較・図面の要素・マトリクス表）は
既定で畳んであり、必要なときだけ開く。マトリクス表に切り替えると該当の設定が自動で開く。

## 使い方

1. 左の「データ」タブにエクセル/CSVをドロップ
2. 列を割り当てて「図をつくる」（起点・終点・重みの列は自動推測）
3. 上部で **ネットワーク図 / マトリクス表** を切替
4. 「見た目」「絞り込み」で調整 → 「図面を書き出す」でPNG、「CSVを書き出す」でデータ

## 受け付ける表の形

**一覧形式**（1行=1つの関係）

| 起点部門 | 終点部門 | 件数 | 起点グループ | 終点グループ | 起点人数 | 終点人数 |
|---|---|---|---|---|---|---|
| 営業第一部 | 開発部 | 12 | 営業 | 事業 | 86 | 124 |

- 重み列がなければ、行数をそのまま件数として数える
- 同じ組み合わせが複数行あるときは 合計／平均／行数 を選べる
- **組織のまとめ方**: 部門名を「_」などの区切り文字の手前でまとめ、上位組織（本部など）単位に集約できる。点数も人数も合算され、まとめた組織内のやり取りは対角（自己ループ）に集まる
- **起点と終点で階層を変える**: 「起点=本部 / 終点=部」のような非対称なまとめ方ができる。マトリクスの行と列がそれぞれ別の粒度になり、図では終点側が角丸四角で描き分けられる。上位・下位の関係にあるマス（本部×その配下の部）は対角と同じ灰色扱い
- 起点・終点の列は「同じ語彙を共有する2列」を探して自動判定（コード列より名称列を優先）
- グループ列は任意（色分けと凡例に使う）
- 人数列は任意（丸の大きさに使う）
- 自由記述（理由・コメント）列は任意。丸やマスをクリックすると読める

**クロス集計表**（1行目と1列目が部門名）

|  | 営業 | 開発 | 人事 |
|---|---|---|---|
| 営業 | 0 | 12 | 3 |
| 開発 | 12 | 0 | 2 |
| 人事 | 3 | 2 | 0 |

- 対称な表は自動判定し、無向モードでは二重計上しない

**文字コード**: UTF-8 / Shift_JIS / UTF-16 を自動判別。

## 主な機能

- 向きあり/なしの切替（既定は**向きあり**。矢印つきでA→BとB→Aを別に扱う。無向にすると合算して1本の線になる）
- レイアウト6種（力学・同心円・円周・格子・階層・手動配置）
- 色の基準に「階層で分ける」を追加。指定した階層（本部・部など）の所属で自動的に色分けされ、凡例もその単位になる
- 丸の大きさ＝組織の人数／1人あたりの量／合計量／相手数／仲介の度合い／一定
- 人数の入れ方は3通り: 列を割り当てる／部門名＋人数の別表から取り込む／部門一覧で直接入力
- グループの展開・格納: まとめた組織の丸をダブルクリックすると、中の部門が枠つきで展開される。展開したグループだけ詳細、他はまとめたままの混在表示ができる
- 組織図シートを並び順マスタとして取り込み、マトリクス表と円周・格子レイアウトをその順に整列（会社名や本部名の列を選べば色分けのグループにも使える）
- 線の太さ＝量に比例・平方根・対数
- 重みの下限、上位N%、部門ごとの表示切替と色指定
- 次数・重み付き次数・媒介中心性のランキング（部門数500超は媒介を省略）
- 書き出し: 図面PNG（方眼・凡例・表題欄つき）／集計CSV（関係一覧＋部門別サマリ、BOMつき）／設定JSON

## 自由記述を読む

理由・コメント列を割り当てておくと、ネットワーク図の丸やマトリクス表のマスをクリックしたときに、
画面右側のパネルにその記述が一覧表示される。

- 矢印の向き（→ 自部門から / ← 相手から）と点数つき
- グループにまとめている場合は、記述の下に元の部門名を併記
- マスをクリックすると、その組み合わせの記述だけを表示
- 右パネルは開くと図の描画領域が自動で詰まるので、図と記述を並べて読める
- ×ボタンか Esc、または図の余白クリックで閉じる
- CSV書き出しにも「起点・終点・量・自由記述」の一覧が付く

## 現状と将来を重ねる

同じ形式の表が2つあれば（例: 現状近接 / 将来近接）、データタブの「5 — 現状と将来を重ねる」で重ね合わせられる。
列の割り当て・まとめ方・並び順マスタはそのまま引き継がれる。

- 重ねると画面上部に **時点の切り替え**（現状 / 将来 / 重ねる / ほか）が出る。ネットワーク図・マトリクス表のどちらを見ていても、そのまま時点だけを切り替えられる
- 「ほか」からは 増える分だけ / 減る分だけ / 差分（将来−現状） を選べる。既定は重ね描き
- 呼び名（現状・将来）を変えると、切り替えボタンの表示もそれに追従する
- **重ね描き**: 現状の関係を無彩色の下地として残したまま、増える分だけを藍緑の線として別に重ねる（図では減る分を描かない）
- 重ね描きのマトリクスは、マスの上段に **合計点（現状＋将来）**、下段に小さく **現状→将来** を出す。例: 合計67 / 42→25
- マスの色は合計点でグラデーションがかかる。下段の色で増減が分かる（増える＝藍緑、減る＝桃色、変わらない＝グレー）
- **新しく生まれる関係**（現状なし→将来あり）は、「ふつうに表示／枠で囲って強調する／それだけ表示」から選べる。「それだけ表示」では関係のない行・列も落ちる
- この強調は **表示する値を「将来」にしたときにも効く**。将来の点数だけを並べた表の上で、現状になかった関係だけが藍緑の枠で囲まれる
- 「増える分だけ」は増加のある関係だけを藍緑一色で描く。「減る分だけ」はその逆
- 差分表示では、増える関係は藍緑、減る関係は桃色。線と丸の大きさは変化量の絶対値
- マトリクスは中央を0とする発散配色になり、値には +/− の符号が付く
- 右パネルに現状・将来・差の3つの数字を並べて表示。自由記述には時点タグが付く
- ランキング表の列も 現状 / 将来 / 差 に切り替わり、差でソートできる
- CSVには関係ごと・部門ごとの 現状 / 将来 / 差 が出力される

## グループの展開

「組織のまとめ方」を設定すると、ネットワーク図でもグループを開閉できる。

- まとめられた組織は六角形、単独の部門は円で表示
- 丸をダブルクリック、絞り込みタブの ▶ / ▼、またはマトリクス表の見出しの ▶ / ▼ で展開・格納（3つの操作は同じ状態を共有する）
- 展開したグループは破線の枠で囲まれ、枠の中では名前から本部名の重複を落として表示
- 「すべて展開」「すべてまとめる」で一括切替
- 展開中は、グループを1点とみなした全体配置 → グループ内を円形配置、の2段階でレイアウトするため枠どうしが重ならない
- グループ内のやり取りは図には線を引かず、マトリクス表の対角と詳細パネルに出す

## 考察

「読み解く」タブで、集計結果から考察の下書きを生成する。現状と将来を重ねている場合は2本立てになる。

粒度は **簡易（3行）** と **詳細（30行程度）** から選ぶ。生成方法は2通り。

### 計算でまとめる（キー不要・オフラインで動く）

集計値から日本語の文章を組み立てる。拾う観点は次のとおり。

- 簡易: 中心となる組織と占有率／上位組織の内と外の比率（件数と量のズレ）／仲介の位置にいる組織
- 詳細: 全体像と密度・中心5組織・内外の比率・仲介の上位・人数あたり・強い結びつき上位7・周辺の組織。
  将来側は変化の総括・新しく生まれる関係・なくなる関係・伸びる既存関係・組織別の増減

### AI用の文章をコピー（追加課金なし）

集計結果とプロンプトをまとめてクリップボードにコピーする。ふだん使っているAIの画面に貼り付けて、
返ってきた文章を考察欄に貼り戻す運用。ツール自体は外部と一切通信しない。

- コピーされるのは集計値・上位25組織・上位25の関係・変化の内訳・自由記述70件など、約8千字のテキスト
- 元のエクセルそのものは含まない
- 「見てほしい観点」を書いておくと、その指示がプロンプトに入る
- 出力形式（【現状】【将来】の見出し）を指定してあるので、返ってきた文章をそのまま2つの欄に分けて貼れる
- 粒度（簡易3行／詳細30行）の指示もプロンプトに反映される

- 生成された文章はそのまま編集できる（下書きとして使う前提）
- 「書き出す図に考察を入れる」をオンにすると、ネットワーク図・マトリクス表のPNGの左下に枠付きで入る
- 設定JSONにも保存される

## マトリクス表

上部の切替で、集計結果をヒートマップ付きのクロス集計表として表示・書き出しできる。

- 行=起点、列=終点。有向なら A→B と B→A が別のマスになる
- 並び順（**組織図の順**／合計順／グループ順／名前順／元データ順）、配色（赤・藍緑・青・緑）、色が最も濃くなる値を指定
- 行・列の見出しラベルは自由入力（例: 「Source（近くにいて欲しいと思っている部署）」）
- **ドリルダウン**: 行・列の見出しの ▶ でそのグループだけ部門レベルに展開。展開した範囲は上と左に帯でくくられ、帯の ▼ でたたむ。展開したグループとまとめたままのグループが混在した表を書き出せる
- 展開してもグループの居場所は動かない（並び替えの主キーをグループ単位で持っているため）。中身は選んでいる並び順の基準で内側に展開される
- 展開中は見出しから本部名の重複を落として表示（`品質保証本部_品質企画部` → `品質企画部`）
- 対角は灰色。まとめた組織内のやり取りがある場合はその合計値が入る
- 値ゼロは空白、行にも列にも値がない部門は自動で省ける
- **起点に出てこない組織**の扱いを選べる（行から外す／行にも列にも出さない／そのまま出す）。回答していない部門は行が空になるため、既定では行から外す
- 絞り込みタブの設定（重みの下限・上位N%・部門の表示切替）がそのまま反映される
- 書き出し: PNG（表題欄つき）／CSV（クロス集計形式）

## 配布

Webサーバーに置く必要はない。単体ファイルなので、社内ファイルサーバー・SharePoint・メール添付などで配布し、
各自のPCでダブルクリックして使う。クライアントデータを外部にアップロードする経路が存在しないため、
情報の取り扱い上も閉じた運用ができる。
